# Credit Risk Prediction

## 📌 Objective
The goal of this project is to predict whether a loan applicant will default on a loan using machine learning models.

---

## 📊 Dataset
Loan Prediction Dataset from Kaggle.

---

## ⚙️ Approach

1. Data Cleaning
   - Handled missing values using mean and mode

2. Exploratory Data Analysis (EDA)
   - Visualized relationships between income, loan amount, and approval status

3. Feature Engineering
   - Encoded categorical variables using Label Encoding

4. Model Building
   - Logistic Regression
   - Decision Tree Classifier

5. Evaluation Metrics
   - Accuracy Score
   - Confusion Matrix
   - Classification Report
